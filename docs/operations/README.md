# 项目操作记录

本目录保存 AI-worker 可在 GitHub 共享和审计的脱敏项目记录。它与源码、n8n 工作流和部署脚本一起进入版本控制，用于回答“为什么改、改了什么、在哪个环境验证、是否部署、还剩什么风险”。

## 记录范围

每个非简单项目任务都应在 `YYYY/YYYY-MM-DD.md` 中记录：

1. 需求与目标；
2. 关键决策及取舍；
3. 代码、配置、模型路由、工作流或文档变更；
4. 本地、隔离环境和生产环境的准确边界；
5. 测试、浏览器、API、模型推理或部署验收证据；
6. 备份与回滚结论；
7. 已知问题、未完成项和下一步。

同一天可以在同一文件中追加多个小节。记录事实必须带日期或环境，不把历史探测结果表述为当前永久状态。代码或生产变更应与对应记录处于同一提交。

## 安全边界

这里只保存脱敏结论，不保存密码、Token、App Secret、私钥、聊天 ID、会话正文、原始日志、数据库、索引、模型权重、备份内容、缓存、PID 或临时文件。需要证明运行状态时，记录探测时间、服务角色、结果和非敏感错误类型，不复制整段日志。
