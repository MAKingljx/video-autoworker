# 概览卡片固定尺寸优化

## 需求

概览页普通卡片不能再随实时内容多少变高或缩短；卡框应保持统一尺寸，消除同排卡片大小不一及框外空白，同时保证窄屏可用。

## 决策

- 只在概览组件范围内修复，不改变全局 `.panel` 行为。
- 非全宽卡片统一固定为 `20rem` 高；关键指标与快捷操作等全宽条带继续自适应。
- 普通卡片按桌面网格保留相对尺寸，尾行自动均分剩余列并撑满可用宽度；窄屏继续自动换成单列。
- 会话和事件等动态长列表改为卡内滚动；空状态在固定内容区内居中。
- 为卡片和行增加稳定的布局语义属性，供真实浏览器几何回归使用。

## 实际变更

- `WidgetGrid` 统一为普通卡片应用固定框架，并标识卡片 ID、固定或流式框架及行容器。
- 概览作用域 CSS 让卡片面板填满框架，固定标题，内容区独立滚动。
- 会话工作台和事件流移除由内容控制的最大高度，统一接入框内滚动区。
- 新增 Playwright 回归，覆盖空数据、10 条会话、`1440px` 桌面、`900px` 平板、`390px` 手机及 Gateway 专属卡片。
