## 本地候选改动

- 清理网页、n8n 工作流、回调、OpenAPI、环境模板和安装器中的重复 `N8N_WEBHOOK_SECRET` 合同；内部通道固定为 `127.0.0.1`，启动器固定 `MC_AUTH_MODE=openclaw-loopback`，拒绝外部 Host、非 loopback 和私网远程例外。
- Gateway token 不再由安全扫描或浏览器生成、收集、返回或拼入 WebSocket URL。新增集中 OpenClaw exec SecretRef 适配器，仅在真实 Gateway 子进程环境中短暂解析；浏览器 URL、日志、SQLite 和命令参数不承载凭据。
- 修复安全扫描对对象型 OpenClaw SecretRef 调用 `.trim()` 的兼容缺陷，改为严格结构校验；密码字段也增加字符串保护，并补充对象凭据回归测试。
- 共享部署锁改为 Bash/Node 共用的原子、权限受控实现；standalone 清单、Next tracing 和启动器同步包含两个新增运行时 helper。启动器拒绝非 loopback 绑定，并把运行数据、数据库、token 和 PID 留在 release 外。
- 保留遗留媒体 CAS、freeze evidence、n8n 首迁和 3017 蓝绿的失败关闭门禁；不自动 apply、不恢复 video lane、不重启 n8n/Gateway/模型/worker，也不创建第二条任务链。
