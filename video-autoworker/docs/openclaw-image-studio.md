# 独立图片创作入口

图片入口采用 `image-studio` 独立 OpenClaw profile。配置、工作目录、会话、网关和服务启停独立；聊天复用 H1 的 Qwen3.6 工具服务。照片封面可使用原片保护模式：原帧保持原生分辨率，文字及擦除素材由现有 Qwen-Image-Edit-2511 BF16 生成，应用自动合成。不渲染软件字体，不下载第二份模型。只有明确允许整图创作时才使用原生 prompt/design 模式。

唯一调用路径为 OpenClaw 的 `aiworker_generate_image` 工具 → 本系统 `image_generation` 应用服务 → 现有 Qwen 生成入口。插件只转换输入、限定会话、查询短收据和展示图片；图像任务状态、幂等、输入快照、执行、取消和恢复由应用服务负责。图像服务使用自己的图像任务数据，不读写视频学习状态或作品封面选中指针。

首次部署关闭全部聊天渠道，飞书由用户准备独立应用后再配置。Gateway 限于回环地址并使用独立 Keychain SecretRef；应用服务限于回环地址，不建立第二套外部账户或共享用户密钥。工具不提供系统 Shell、生产管理或指定其他收件人的能力。DM 按账户、渠道和用户隔离。

提交快速返回受理结果；模型按单并发后台运行。重复请求返回同一任务，参数或来源变化则拒绝复用旧幂等键。生成入口与应用 Worker 使用同一模型执行锁；等待资源期间仍可取消，不设置统一生成总时限。输入文件在受理时保存受控快照。

终态 `GENERATED_PENDING_REVIEW` 表示候选 PNG 和收据通过当前模式的检查。中文字、主体、字体效果和发布适用性仍需审看，不能当作已经采用或发布。原生整图模式标记 postProcessing=false；原片保护模式明确标记 postProcessing=true 和 original_photo_plus_local_model_assets，不能把自动合成称为整张模型原生输出。

## 原片保护与高清输出

工具 submit 的 protected、prompt、design 三选一。protected 的 schema 是 aiworker-protected-cover/v1，包含 eraseRegions 和 textLayers；每个文字层提供精确 text、原图像素 box、可选 style 和 align。只允许一张原图，保护模式不填写外层 width/height；输出严格保留源图尺寸。擦除和文字各最多四个矩形，矩形必须在图内且彼此不交叠，总编辑面积不超过40%。原图采用受控受理快照，不改写素材文件。

每个擦除区域独立生成有上下文的修补素材，只回贴指定区域。每一行文字独立生成原生高清字形素材；第一次质量未通过时最多重试一次，已成功的行不重算。应用抠取模型字形并只做缩小和合成，不放大小字图冒充高清，不对全片调色、磨皮或锐化。源视频本身的失焦、压缩和运动模糊仍是画质上限，应优先选择清晰原帧。

相同会话后续修正时，应用可在最近12个受控终态任务中复用匹配的原生素材。擦除必须同原帧、同区域、同模型及采样参数；文字只取已封存合格结果中实际选中的素材，并要求当前提示词与参考像素一致。原生素材和模型收据保持原路径、原字节，派生缓存文件不改变请求载荷或幂等身份；新任务仍重新核对文字实际ROI及照片保护。调用方不提供缓存路径或跨会话素材标识。

缓存来源的原生素材及收据是后续结果的完整性依赖，不能当作临时无用输出清理。产生含缓存引用的结果后，回退必须先验证旧版本能读取该格式；不自动还原数据库或回退到不理解引用关系的代码，优先在当前数据与已验证制品上修复。

验收对原生素材及模型收据、最终每一行实际像素的 Apple Vision 识别、编辑区外全部RGB像素进行独立核验。模型错字或漏字不能用软件字体补齐。成功结果冻结实际合成区域和哈希；后续提示词或抠图实现更新后，历史图片仍按封存数据完整性回读，不重新生成或用新算法改写旧图。

完成提醒后，同一对话先用 result 获取原尺寸成品，再用 inspect 获取源图和成品的原生 image 图块。inspect 只能读取本会话已有终态任务，不接受任意文件路径。机器检查通过不能替代目视审核；模型无法消费图块时必须报告未完成视觉自检。该模式实现与真实生产验收分别记录在当天运维记录中。

服务中断后先核对已有图像与收据；结果不明的已运行任务进入 `RECONCILE_REQUIRED`，不自动重跑。取消只停止该 Worker 持有的子进程组。任务保存受理时的源码及生成器摘要，升级不能重写旧任务的版本证据。

完成提醒仅排入原 OpenClaw 会话事件，不直接发送飞书。提醒订阅是运输信息，不是另一套任务状态。任务和候选可以通过 `status`、`result` 回读；飞书配置和真实送达另行验收。

部署安装器分别管理应用组件和独立 profile，生产源码绑定 canonical Git 提交，制品成员及摘要完整审计。应用、插件和运行时分别按实际变化安装；无需为新增入口重启现有三个 Gateway 或视频服务。安装失败保留本次归属收据，先核对后按同一操作续作；未知既有目录、配置或服务禁止覆盖。

完成提醒通过官方runtime-store共享同一个已启动运输对象，以适应OpenClaw的服务启动/工具发现注册模式，业务状态仍由应用服务拥有。当前已在H1部署并实测，飞书留待用户配置，详细证据见 `docs/operations/2026/2026-10-04.md`。
