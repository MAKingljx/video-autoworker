# 独立图片创作入口

图片入口采用 `image-studio` 独立 OpenClaw profile。配置、工作目录、会话、网关和服务启停独立；聊天复用 H1 的 Qwen3.6 工具服务，整张图片和中文由已部署的 Qwen-Image-Edit-2511 BF16 输出。没有人工排字，也不下载第二份模型。

唯一调用路径为 OpenClaw 的 `aiworker_generate_image` 工具 → 本系统 `image_generation` 应用服务 → 现有 Qwen 生成入口。插件只转换输入、限定会话、查询短收据和展示图片；图像任务状态、幂等、输入快照、执行、取消和恢复由应用服务负责。图像服务使用自己的图像任务数据，不读写视频学习状态或作品封面选中指针。

首次部署关闭全部聊天渠道，飞书由用户准备独立应用后再配置。Gateway 限于回环地址并使用独立 Keychain SecretRef；应用服务限于回环地址，不建立第二套外部账户或共享用户密钥。工具不提供系统 Shell、生产管理或指定其他收件人的能力。DM 按账户、渠道和用户隔离。

提交快速返回受理结果；模型按单并发后台运行。重复请求返回同一任务，参数或来源变化则拒绝复用旧幂等键。生成入口与应用 Worker 使用同一模型执行锁；等待资源期间仍可取消，不设置统一生成总时限。输入文件在受理时保存受控快照。

终态 `GENERATED_PENDING_REVIEW` 只表示候选原生 PNG 和收据通过完整性及图像解码检查。中文字、主体、字体效果和发布适用性仍需审看，不能当作已经采用或发布。标准冰晶纪实设计仍限一张无封面大标题的原帧；自由提示词保留通用参考能力。

服务中断后先核对已有图像与收据；结果不明的已运行任务进入 `RECONCILE_REQUIRED`，不自动重跑。取消只停止该 Worker 持有的子进程组。任务保存受理时的源码及生成器摘要，升级不能重写旧任务的版本证据。

完成提醒仅排入原 OpenClaw 会话事件，不直接发送飞书。提醒订阅是运输信息，不是另一套任务状态。任务和候选可以通过 `status`、`result` 回读；飞书配置和真实送达另行验收。

部署安装器分别管理应用组件和独立 profile，生产源码绑定 canonical Git 提交，制品成员及摘要完整审计。应用、插件和运行时分别按实际变化安装；无需为新增入口重启现有三个 Gateway 或视频服务。安装失败保留本次归属收据，先核对后按同一操作续作；未知既有目录、配置或服务禁止覆盖。

完成提醒通过官方runtime-store共享同一个已启动运输对象，以适应OpenClaw的服务启动/工具发现注册模式，业务状态仍由应用服务拥有。当前已在H1部署并实测，飞书留待用户配置，详细证据见 `docs/operations/2026/2026-10-04.md`。
