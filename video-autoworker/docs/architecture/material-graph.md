# 素材关系图谱

图谱是现有素材库的只读视图。每份完整视频对应一个节点，关系端点只能是两个视频。一个视频的多个场景只贡献标签及时间码依据，不生成重复视频点。区域文字帮助浏览聚集关系，不能充当主题父节点。

## 数据路径

`material-graph-panel → GET /api/materials/graph → getMaterialsGraph → 现有素材读取适配器 → SQLite场景索引`

`material-graph-source`合并明确属于同一视频的场景，`material-graph`生成客户端布局和代表性连接，父素材页面复用已有播放器完成回跳。没有第二条学习、审核或调度链。

场景维度读取结构化场景、地点及环境字段；情绪维度读取结构化emotion/emotions字段。统一大小写、空白和分隔符，不从文件名、自由摘要或原始转写猜标签；未识别/未知项不参与关联。连线代表标签共有，不代表内容相同、因果成立或人工审核通过。

## 来源绑定与限制

按作品内明确的来源文件名或路径匹配；显式来源冲突或不在当前作品内时拒绝配对。没有来源提示时，仅可使用作品确实只有一个视频的确定性归属，或`pipeline-视频文件名`的精确对应，不能采用“当前选中/第一个视频”回退。

历史流水线若未在场景标注中保存源文件，可在作品目录放一份受控的`material_sources.json`：`{"schemaVersion":1,"pipelines":{"pipeline-ep2/pipeline":"raw-data/原视频.mp4"}}`。键是相对作品目录的索引目录，值必须精确对应本作品`raw-data`内唯一一个完整视频。它仅提供显式来源证据，不更改SQLite或学习结果；与场景字段冲突、文件不存在、清单损坏或指向作品外时仍不配对。回填前须用原始任务/上传记录或视频帧比对逐项核实，不得由`ep`序号推断文件名。

读取器支持`pipeline/material_index.sqlite`和`pipeline-ep*/pipeline/material_index.sqlite`；同一集目录若还存在旧的根级索引，优先读取嵌套索引，避免重复或误选。接口中的流水线名使用相对路径区分各集。

读取上限为300个视频、3000条场景，视频详情最多24条，节点标签来自本次全部已读取场景。接口返回totalMaterials、scannedScenes、unmatchedScenes、unreadablePipelines和truncated。用户可缩小作品范围继续查看，不能把部分读取解释成全库已分析。

布局和关系由有限、确定性的本地计算生成，无持续力模拟和新依赖。为控制密度显示代表性近邻关系，最多1800条；这些边全部有共同标签，未绘制的边不表示素材不存在其他共性。没有标签的素材仍显示为孤立点。

## 本地开发预览

`scripts/preview-material-graph.mjs`接受一个新建的绝对状态目录、合成MP4文件与回环端口，准备明确命名的验收素材库后运行当前源码的Next开发服务。它使用项目Node 22、隔离数据库、现有桌面访问模式，并关闭调度器；不修改正式素材根、默认模型或真实OpenClaw配置。状态目录已存在时停止，避免覆盖历史或真实资料。

该脚本只用于本地人工预览。用户看到的示例关系来自测试标注，不是模型对合成图样的实际理解。生产接入使用现有素材配置及授权方式，不能把预览环境变量带入正式部署。
