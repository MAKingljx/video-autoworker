# Qwen 当前入口图片会话收敛生产发布

## 问题与边界

2026-11-04 的跨午夜飞书会话反复以不完整参数调用旧图片工具。通用导演脑投影掩盖了图片错误和任务回执，模型无法识别无进展而循环调用；同一时期流式卡片关闭导致无效更新日志。

本次只调整 OpenClaw 图片适配、会话压缩和飞书投递配置。图片应用继续是唯一队列、幂等、取消、媒体与模型调用权威；没有新增图片任务、改写候选、处理视频学习任务或改变模型路由。

## 实际发布

- 本次运行时使用的受管源码提交为 `5c42f82`。H1 使用同一干净提交完成定向测试、隔离预检和生产维护。
- `qwen-current / second-original` 与 `image-studio` 均加载 `aiworker-image-command 0.4.0`。两个入口只保留五个动作明确图片工具，旧混合工具已移除。
- image-studio 的旧 `0.2.2` config-origin 来源已精确退休并迁移到官方 profile extension。安装过程使用官方 plugin install、registry refresh、doctor 和 Gateway 重启；SSH Keychain 会话不可用时，仅使用一次性受控 GUI 维护任务，不导出或记录凭据。
- qwen-current 的飞书流式模式为 `off`。会话收敛已通过 Gateway CAS 热更新到 `4096` 最近 token、`3` 个最近回合、`256kb` 活跃转写阈值、`240` 秒和已启用的中途预检；退役字段未写入。
- Gateway 热更新日志只保存受限配置事件、游标和文件身份，原始日志内容不进入操作证据。
