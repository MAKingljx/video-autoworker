# Qwen 当前入口图片会话收敛（候选）

## 触发原因

`qwen-current / second-original` 的一条飞书会话在 2026-11-04 深夜跨越到次日。会话先完成一次自动上下文压缩，随后反复以只有 `action: submit` 的不完整参数调用图片工具。图片服务没有收到有效任务，导演脑长期会话投影又把真实错误与任务回执压缩为泛化完成状态，模型无法判断无进展而重复调用，最终由循环保护终止。飞书流式卡片在同一期间反复报告已关闭，造成无效日志与用户侧进度不可见。

## 模块边界

- 图片命令插件只负责严格的模型侧动作契约、会话范围转换、唯一图片应用调用和安全短回执；不拥有队列、模型或视频任务状态。
- 导演脑投影插件只负责长期会话的安全回执投影，允许保留图片任务编号、状态、错误码与下一步，不保存提示词、路径、图片字节或其他私密参数。
- 会话收敛配置只负责上下文阈值和安全压缩；不重新提交图片任务。
- 飞书投递策略只关闭流式卡片更新，保留普通最终消息和已有任务提醒；不改变模型、工具或图片服务。
- qwen-current 工作区指导以受控片段替换旧 SDXL/18093 直接调用说明，不覆盖用户的其它工作区内容。

## 候选实现与本地验证

- 图片插件升级为 `0.4.0`，退役混合动作入口，改为三种严格提交工具、一个按任务编号操作的任务工具和一个可检索说明工具。相同无进展提交在同一会话第二次即被阻止。
- 导演脑投影对图片工具保留安全回执，并将无效提交投影为错误而不是成功。
- qwen-current 收敛参数改为保留 4096 token、3 个最近回合、256 KiB 活跃转写阈值；仍使用官方支持的 safeguard/mid-turn precheck 配置，不写入已退役字段。
- 飞书投递策略使用官方 `channels.feishu.streaming.mode: off`，不修改 OpenClaw 安装目录。
- 已通过图片插件 50 项、导演脑投影 295 项、图片能力契约 5 项、图片服务与 profile 安装 68 项、投递策略 4 项、工作区指导 3 项，以及会话收敛矩阵 26 项定向检查。

## 生产计划

生产发布前需确认 qwen-current 与 image-studio 没有在途请求、图片队列为空、配置和插件恢复点可用。随后从同一 Git 提交安装图片插件到两个已声明入口，安装 qwen-current 导演脑投影，应用工作区指导、飞书投递策略与会话收敛配置，并只重启受影响的两个 Gateway。不会重置历史飞书会话、重试旧图片请求、改写图片候选或视频任务。
