用户授权在默认生产节点部署第4个独立 OpenClaw profile，复用现有完整中文图片生成能力；飞书入口先关闭，待用户准备后配置。新增能力不改变已有模型权重、视频学习任务、作品封面指针或已有 Gateway 配置。

## 本地候选

Qwen 既有生成函数增加共享模型锁和可取消的等待选项，仍只有一条模型生成实现。部署安装器分开管理应用组件与独立 profile，保持源码固定、完整成员校验、只创建批准的新对象和已归属失败续作。

新组件以本次制品及短运行收据管理；共享生成脚本旧版本可从已有 Git 提交恢复。未知运行身份先停止本次副作用并核对，不自动重提交或回滚其他服务。飞书账户、凭据、外部消息和送达不在本次启用范围内。

## 现场兼容修复

首次组件启动已健康，但外部冷只读 SQLite WAL 检查不能打开；完整性检查统一到应用自身连接，再由安装器回读健康结果及真实数据库身份，不使用会忽略 WAL 的 immutable 模式。只替换本次已归属且没有任务、尚未验收的组件，原数据库和输出保留。

Keychain 在 SSH 审计会话中状态为2，而服务实际 GUI 会话为7，已解锁且可写。新凭据创建与 profile 安装在合法 GUI 服务会话执行；固定 security actor 仅创建本次独立条目，密码经标准输入和内存回读，不进入参数、文件或日志。未启动的准备配置按原摘要迁移到相同插件的新制品位置。临时只读探测服务已退出。

Keychain 新条目已在 GUI 会话创建。现场发现 security 交互输入附带未知 quit 命令，导致凭据写入成功后整段返回1；只读元数据确认条目已存在后，沿原准备配置续作，不重复创建。创建器改为 EOF 结束输入，并通过真实 macOS security help 无写入回归。此修正仅安装器，图像应用和模型代码未变，原制品可以复用。

独立 Gateway 已健康。官方 agent CLI 路径不会自动选择 SecretRef；运维调用复用既有单一 SecretRef 适配器，将值仅放进子进程环境，并在合法 GUI 会话运行，不新增鉴权或向参数/文件写 Token。新增薄 CLI 转发器用于真实会话验收，不参与图像队列、模型执行或外部飞书发送。
