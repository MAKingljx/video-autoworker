# H1 OpenClaw 可插拔图片能力首批接入（2026-11-04）

## 目标与范围

将 H1 的唯一图片应用以可插拔能力接入 `qwen-current / second-original`。本批只更新图片应用配置和该 profile；不修改视频学习、3017、n8n、模型权重、`gpt-main`、`qwen-weixin-new`、`image-studio` 的运行配置或任何选中封面。

## 设计

- `ops/openclaw/image-capability-attachments.json` 是入口声明的唯一来源，绑定 profile、agent、Gateway 端口、状态目录和受控媒体目录。
- 图片队列、GPU 串行、幂等、取消、结果和媒体权限继续由 `127.0.0.1:18095` 的唯一图片应用负责。
- profile 仅获得 `aiworker_generate_image`；不会获得视频任务、系统执行、3017、n8n 或封面采用权限。
- 插件安装使用官方 `plugins install --no-enable`，安装后必须确认配置字节未变；仅由一次 Gateway CAS 配置补丁启用插件和工具。失败恢复只在配置差异可证明属于本组件时执行。

## 纠正的部署边界

首次预检发现两项通用问题：不能用新模板重算历史服务的配置摘要；官方插件安装默认会修改配置。前者已改为核验历史密封收据绑定的实际配置和 plist，后者改为“安装但不启用，再 CAS 启用”。中间产生的 qwen 半配置在验证备份后精确恢复，随后才执行最终发布；没有保留半启用插件、图片任务或数据改写。

## 后续

新增其它 OpenClaw 入口时，先经用户授权在能力清单增加完整声明，再复用相同的受控安装、真实会话验收和恢复流程；不得复制图片队列或为入口单独实现图片业务链。
