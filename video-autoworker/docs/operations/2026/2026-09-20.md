# 2026-09-20 音频转写无固定超时修复

## 需求与根因

5 个视频的源文件均包含可读的 PCM 音轨，手工调用 `large-v3-turbo` 也能完成转写。失败来自媒体节点给 Whisper 子进程设置了固定超时；模型加载或长片段处理超过该预算时，任务被误杀并记录为 `N8N_MEDIA_COMMAND_FAILED`。

## 实际改动

- `src/lib/n8n-media-execution.ts` 的音频转写不再传入固定 `timeout`。子进程正常退出、非零退出、输出超过缓冲区或系统终止时仍按原错误合同失败；ffmpeg 探测、抽音轨和抽帧的保护超时保持不变。
- GitHub 提交：`5404a60c1dee7e18dd63ad012cca400cde6ae095`。
- 生产 Web 制品：`5404a60c1dee7e18dd63ad012cca400cde6ae095-runtime`，蓝绿 generation 14，当前槽为 green。
- 生产独立 Worker 制品：`ea8d0bbcac9d4a43a9c38634526fb3d8ea3f8b08e6406f06fbdb116bdf80ef99`，PID 89206，健康并持有唯一租约。
